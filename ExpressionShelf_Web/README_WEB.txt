Expression Shelf Web 0.6.5 (트랜지션 10종 추가)
웹 스타일 모션 갤러리 패널 · 기존 ExpressionShelf.jsx와 별개로 동작

[v0.5.1 수정 사항]
- 저장 도중 실행하던 AE 프로젝트 자동 저장과 saveFrameToPng 렌더링을 제거했습니다.
- Ctrl+S로 이미 저장된 AEP 사본만 보관합니다. 미저장 상태면 먼저 저장하도록 안내합니다.
- 썸네일은 카드의 "썸네일 PNG 등록"에서 따로 선택합니다. 기존 썸네일은 유지합니다.
- 초기화 시 저장/불러오기 함수를 명시적으로 등록하고 빈 응답 메시지에 호출명을 표시합니다.
- 보관 폴더의 last-operation.txt에 AEP 복사 시작/보관 완료 단계를 기록합니다.
- 실제 사용자 환경에서 멈춘 지점은 아직 확정하지 못했습니다. AE 실기 검증은 필요합니다.

[새 기능: 레터박스]
- 상단 레터박스 탭에서 2.39:1, 2.35:1, 2:1, 1.85:1 화면비 또는 직접 입력 비율을 선택합니다.
- 색상 피커/HEX 코드와 0~2초 페이드 인·아웃 설정 후 활성 컴프에 도형 레이어를 생성합니다.
- 생성된 ES Letterbox 레이어의 효과 컨트롤에서 막대 높이·색상·페이드 시간을 편집할 수 있습니다.
- 16:9 컴프에는 보통 2.39:1 또는 2.35:1을 고릅니다. 16:9 화면비는 4:3 컴프에 적용합니다.
- 실행 취소는 Ctrl+Z. 적용 대상 레이어 지정은 필요하지 않습니다.

[새 기능: 타이포 보관함]
- 텍스트, 도형, 장식, 효과, 텍스트 애니메이터, 키프레임, 익스프레션을 네이티브 AEP에 보관합니다.
- 이름/분류로 저장, 별도 PNG 썸네일 등록, 검색/분류 필터, 다른 프로젝트에 새 사본 불러오기.
- "선택 레이어 지정"과 별개 기능입니다. 선택한 일부 레이어가 아니라 현재 활성 컴프 전체가 대상입니다.

[타이포 저장]
1. 디자인 전체를 한 컴프에 구성하거나 프리컴프하고, 그 컴프를 열어 대표 프레임으로 이동합니다.
2. Ctrl+S로 프로젝트를 일반 .aep 파일로 먼저 저장합니다. 컴프 이름은 프로젝트 내에서 고유해야 합니다.
3. 타이포 보관함 탭 → 이름/분류 입력 → "저장된 AEP로 타이포 보관".
   Ctrl+S로 저장이 완료된 AEP만 복사합니다. 미저장 변경 사항이 있으면 안내하고 중단합니다.
   작업 프로젝트를 닫거나 축소하지 않고 현재 파일 경로를 유지합니다.
4. 같은 이름으로 다시 저장해도 별도 항목이 생기며 기존 항목을 덮어쓰지 않습니다.
   자동 썸네일 렌더링은 제거했습니다. 저장 후 카드의 "썸네일 PNG 등록"으로 이미지를 선택하세요.

[타이포 불러오기]
- 넣을 작업 컴프를 열고 재생 헤드를 옮긴 뒤 카드의 "현재 컴프에 추가".
  새 프리컴프 레이어가 원본 100% 크기/중앙 위치로 현재 시간부터 추가됩니다.
  남은 컴프 길이가 짧으면 레이어 끝을 잘라 맞춥니다. Ctrl+Z로 가져오기를 취소할 수 있습니다.
- "컴프 불러와 열기"는 새 사본을 가져와 컴프를 엽니다. 에펙에서 재생해 모션을 확인하세요.
  패널 썸네일은 정지 이미지입니다. 두 버튼은 각각 매번 새 사본을 가져옵니다.
- 문구 수정: 추가된 프리컴프를 더블클릭 → 내부 텍스트 레이어 편집.

[저장 범위 / 백업]
- v0.5는 프로젝트 전체 AEP 스냅샷 방식입니다. 불러오면 다른 컴프도 별도 프로젝트 폴더에
  함께 들어옵니다. 타임라인에는 저장 대상으로 지정한 타이포 컴프만 넣습니다.
  전용 작은 타이포 프로젝트에서 저장하면 파일 크기와 불러오는 항목 수를 줄일 수 있습니다.
- 문서 폴더/ExpressionShelf/Typography/typo_... 에 design.aep, preview.png, info.txt를 저장합니다.
  확장 설치 폴더 밖이므로 재설치/제거 때 보관함을 지우지 않습니다. 폴더 전체를 백업하세요.
  정리가 필요하면 "저장 폴더 열기"로 항목 폴더를 별도 백업 위치로 옮기고 새로고침하세요.
- 폰트/외부 플러그인은 별도로 필요하며 외부 이미지/영상 원본은 자동 수집하지 않습니다.
  다른 PC로 옮길 때는 AE 파일 > 종속성 > 파일 수집(Collect Files)과 별도 폰트/플러그인 설치가 필요합니다.
- 원본 AEP를 복사하므로 컴프 내부 속성은 유지되지만, 프로젝트 색상/표현식 엔진 설정 차이,
  같은 이름의 comp("...") 전역 참조 등은 가져온 프로젝트에서 확인해야 합니다.
- 환경 설정 > 스크립팅 및 표현식 > 스크립트의 파일 쓰기 및 네트워크 액세스 허용을 켜주세요.
- 실제 After Effects에서의 저장/불러오기/렌더링은 이 제작 환경에서 실행하지 못했습니다.
  파일 처리와 AE/패널 모의 테스트를 거친 시험판입니다.

[무엇이 다른가]
- 기존 모션 51개와 별도 트랜지션 28개, 총 79개 카드가 패널 안에서 실제로 움직이는 미리보기로 재생됩니다.
  미리보기는 에펙에 들어갈 익스프레션을 그대로 계산해서 그리므로, 적용 결과와 같은 수식입니다.
  (에펙의 wiggle·렌더링과 완전히 같지는 않습니다. 정확한 확인은 "에펙에서 미리보기")
- 분류/느낌 칩, 검색(이름·이징·설명), 재생 속도 0.5×/1×/2×, 일시정지
- 카드를 누르면 상세 패널: 큰 미리보기, 길이 슬라이더, 이징 선택과 곡선, 수치 슬라이더,
  예제(도형/텍스트·문구), 시작 지연/레이어 간격/덮어쓰기, 코드 보기·직접 수정
- 넓은 패널에서는 오른쪽 사이드, 좁은 패널에서는 아래에서 올라오는 시트로 열립니다.

[설치]
1. 에펙을 종료합니다.
2. 이 폴더의 "설치하기.bat"을 더블클릭합니다.
   - 확장 파일을 %APPDATA%\Adobe\CEP\extensions\ExpressionShelf_Web 에 복사합니다.
   - 서명하지 않은 확장을 켜기 위해 PlayerDebugMode=1 을 현재 사용자 레지스트리
     (HKCU\Software\Adobe\CSXS.9~12)에 기록합니다. 직접 만든 CEP 확장에 흔히 쓰는 설정이며,
     다른 서명 없는 확장도 로드될 수 있게 됩니다.
3. 에펙 실행 > 창(Window) > 확장(Extensions) > Expression Shelf Web

[업데이트]
패널 상단의 "업데이트 확인"을 누릅니다. 새 공개 버전이 있으면 "다운로드 및 설치 예약"을 누르세요.
다운로드 파일의 크기와 SHA-256을 검사한 뒤 설치 도우미 실행을 확인합니다. 현재 프로젝트를 저장하고
After Effects를 완전히 종료하면 확장 폴더에 설치됩니다. 다음 실행 때 설치 완료·실패 결과가 표시됩니다.
설치가 진행되지 않으면 %TEMP%\ExpressionShelf_update_log.txt 에서 도우미 시작, 종료 대기, 복사, 오류 단계를 확인하세요.
GitHub의 초안 릴리스는 공개 전이므로 업데이트 목록에 나타나지 않습니다.

제거: "제거하기.bat" (확장 폴더만 삭제하고 PlayerDebugMode는 그대로 둡니다)
파일을 고친 뒤에는 설치하기.bat을 다시 실행하고 패널을 닫았다 여세요.

[사용 순서]
1. 작업 컴포지션 타임라인에서 적용할 레이어를 선택합니다. 미리 지정할 필요는 없습니다.
2. 카드 선택 → 길이·이징·수치 조절 (미리보기가 바로 바뀝니다)
3. 필요하면 "에펙에서 미리보기"로 실제 컴포지션 확인
4. 타임라인에서 적용할 레이어를 다시 선택하고 "선택 레이어에 적용"을 누릅니다. 결과는 상세 패널의 "적용 결과"에 표시되고 Ctrl+Z 한 번으로 취소할 수 있습니다.

[브라우저에서 열기]

(일부 브라우저는 file:// 에서 스크립트를 막으므로, 그 경우 로컬 웹서버로 여세요.)

[시험판 제한]
- "내 프리셋" 저장/불러오기는 아직 없습니다. 필요하면 기존 ExpressionShelf.jsx 패널을 쓰세요.
- 새 사용자 코드("새 코드") 입력 화면은 없습니다. 기본 모션의 코드를 수정해서 적용할 수는 있습니다.
- CEP는 Adobe가 UXP로 옮겨 가는 중인 방식입니다. 현재 에펙에서는 동작하지만 장기 지원은 보장되지 않습니다.
- 에펙 버전 2022(22.0) 이상 대상입니다.

                   현재 웹 버전 수정은 shelf-core.js에서 진행하세요.

[장면 전환 적용 순서]
1. 이전 장면 A를 아래, 다음 장면 B를 위쪽 트랙에 배치합니다.
2. B의 시작점을 전환 시작 위치에 놓고, A가 전환 종료까지 남도록 겹칩니다.
   예: 길이 600ms이면 최소 0.6초 겹치세요.
   시작 지연/레이어 간격을 사용하면 그 지연 시간까지 추가로 겹쳐야 합니다.
3. 트랜지션 탭에서 효과를 선택하고 길이·수치를 조절합니다.
4. 타임라인에서 다음 장면 B 레이어만 선택하고 '선택한 다음 장면에 적용'을 누릅니다.
5. 정확한 합성은 에펙에서 확인합니다.

여러 요소로 구성된 장면은 먼저 프리컴프하여 B 한 레이어로 만드세요.
원하는 결과를 위해 컴포지션 전체를 채우는 불투명한 2D 장면을 권장합니다.
슬라이드는 컴포지션 폭/높이만큼 이동합니다.
트랜지션은 부모 연결 없는 2D 레이어용입니다. 3D, 부모 연결, 조정, Null 레이어는 건너뜁니다.
위쪽 B가 원래 반투명하거나 화면을 채우지 않으면 끝난 뒤에도 아래 A가 비칩니다.
이 프리셋들은 B에 익스프레션과 필요한 기본 이펙트를 적용합니다.
컷을 자동으로 탐색하거나 A/B의 순서, 길이, 시작점, 오디오를 편집하지 않습니다.
이징의 오버슈트 성질에 따라 중간에 경계가 드러날 수 있습니다.

[기존 전환을 바꿀 때]
먼저 Ctrl+Z로 이전 적용을 취소하거나 기존 전환의 익스프레션/ES 이펙트를 제거하세요.
덮어쓰기는 새 프리셋이 사용하는 속성만 교체합니다. 이전 프리셋만 사용하던
다른 속성이나 이펙트는 자동으로 지우지 않으므로 효과가 중첩될 수 있습니다.

[미리보기 범위]
패널에서는 동일 수식을 브라우저 방식으로 표시합니다.
블러·와이프의 픽셀 처리, 글꼴, 이펙트 방향 등은 에펙과 다를 수 있습니다.
'에펙에서 미리보기'는 실제 장면 A/B 프리컴프를 만들어 B에 전환을 적용합니다.
B는 미리보기의 0.35초부터 시작합니다. 미리보기 기본 길이는 6초입니다.
큰 시작 지연을 지정하면 이 구간에 전환이 안 보일 수 있습니다.
갱신 시 이전에 생성한 예제 레이어와 다른 곳에서 사용하지 않는 예제 소스만 정리합니다.

- DOM 모의 환경에서 탭 전환, A/B 장면 생성, 미리보기 수식 실행, 검색, 기존 텍스트 화면을 검사했습니다.
- 에펙 호스트 모의 환경에서 A/B 생성, 갱신 정리, 실패 시 이전 예제 유지, 일반 모션 복귀를 검사했습니다.
- 호스트 모의 환경에서 필름 번·플래시·컬러 스윕 보조 레이어, 미리보기 정리, 선택 레이어 적용을 검사했습니다.

[0.3 추가: 글리치 / 라이트 리크]
트랜지션 탭에 2종을 추가해 총 12종입니다. 기존 모션은 51종입니다.

글리치 전환:
- 순간적인 가로·세로 떨림, 가로 늘어남, 불투명도 깜빡임으로 디지털 끊김을 만듭니다.
- 떨림(px), 변화 횟수(회/초), 가로 왜곡(%)을 조절합니다.
- 기본 길이는 450ms입니다. 0.4부터 RGB 분리와 색 플래시를 지원합니다. 픽셀 블록과 오디오 효과는 포함하지 않습니다.

라이트 리크 (Light Leak):
- 따뜻한 주황·노란색 빛이 화면을 가로질러 지나가며 B로 넘어갑니다.
- 빛 강도(%), 빛 폭(%), 길이, 이징을 조절합니다. 기본 길이는 1100ms입니다.
- 외부 영상이나 별도 플러그인 없이 도형과 기본 Gaussian Blur로 빛을 생성합니다.
- 적용 시 지정한 B 바로 위에 Screen 모드의 'ES Light Leak · B이름' 레이어를 1개 만듭니다.
- 빛 레이어는 B와 시작/끝 구간을 맞추며 익스프레션으로 전환 구간 밖에서는 투명해집니다.
- B를 나중에 이동하거나 자르면 빛 레이어의 시간도 함께 맞춰 주세요.
- B의 위치/크기와 무관하게 컴포지션 공간에서 빛이 움직입니다.
- 동일 B에 재적용 시 덮어쓰기 옵션을 켜면 이 도구가 만든 기존 빛 레이어를 교체합니다.
  기존 빛 레이어가 잠겨 있으면 건너뜁니다. 적용 한 번은 Ctrl+Z 한 번으로 취소됩니다.
- 다른 전환으로 바꿀 때는 기존 적용을 실행 취소하거나 빛 레이어와 B의 기존 익스프레션을 제거하세요.
- 코드창은 B의 페이드용입니다. 빛 레이어 코드는 수치·길이·이징에서 별도로 생성됩니다.
  이징은 빛의 이동에 적용됩니다. B의 페이드는 전환 중간 구간에서 부드럽게 진행합니다.
- 빛은 그 아래의 전체 합성에 Screen으로 합쳐집니다. 원하지 않는 로고/자막은 빛보다 위에 배치하세요.
- 브라우저 CSS 블러/Screen과 실제 에펙 블러/합성은 결과가 완전히 같지는 않습니다.

두 전환 모두 다른 트랜지션과 동일하게 A와 B를 겹친 뒤 B만 지정해 적용합니다.

[0.4: 글리치의 RGB 분리 / 색 날림]
기존 '트랜지션 → 글리치 전환'에 수치 2개를 추가했습니다.
- RGB 분리 폭(px): 기본 28, 범위 0~200. 0이면 RGB 잔상 레이어를 만들지 않습니다.
- 색 날림(%): 기본 45, 범위 0~100. 0이면 색 플래시 레이어를 만들지 않습니다.
기존 떨림, 변화 횟수, 가로 왜곡, 길이는 그대로 조절할 수 있습니다.

RGB는 원본을 R/G/B 채널로 나눈 3개의 복제 레이어를 Add로 겹쳐
채널별 방향으로 어긋나는 컬러 잔상을 만듭니다. 원본 장면은 유지됩니다.
단순히 회색 영상에 색을 칠하는 방식이 아니라 실제 입력 채널을 분리합니다.
색 날림은 흰색/마젠타/시안의 Add 플래시로 밝기와 색을 순간적으로 밀어 올립니다.
영상의 노출 값을 직접 변경하거나 색 정보를 영구적으로 잘라내는 기능은 아닙니다.
프로젝트의 비트 깊이와 색상 관리에 따라 하이라이트 모양이 달라질 수 있습니다.

적용 시 기본적으로 다음 보조 레이어 4개가 B 위에 생성됩니다.
  ES RGB R · B이름
  ES RGB G · B이름
  ES RGB B · B이름
  ES Color Flash · B이름
RGB 복제 레이어의 오디오는 꺼서 소리가 중복 재생되지 않도록 했습니다.
보조 레이어는 전환 구간 밖에서 투명해집니다. 입력 장면의 소스 시간과 키프레임을 복사합니다.
B를 나중에 편집/이동/트림하면 보조 레이어도 함께 수정하거나 다시 적용하세요.
매트가 있는 장면은 먼저 프리컴프하세요. 부모 연결 없는 2D 장면용입니다.

'기존 항목 덮어쓰기'를 켜고 다시 적용하면 이 도구가 만든 같은 B의 보조 레이어를 교체합니다.
보조 레이어 중 잠긴 레이어가 있으면 건너뜁니다.
다른 종류의 전환으로 바꿀 때는 Ctrl+Z로 이전 적용을 취소하거나
B의 기존 전환 익스프레션과 보조 레이어를 함께 제거하세요.
코드창은 B의 기본 모션용입니다. RGB/플래시는 수치와 길이에서 별도로 생성합니다.

기존 63개 프리셋의 B용 생성 코드 보존, RGB 채널 선택값,
구간 밖 잔상/플래시 투명도, 복제 오디오 비활성화, 보조 레이어 중복 방지,
