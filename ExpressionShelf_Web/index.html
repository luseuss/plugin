만들어 둔 타이포, 다시 꺼내 쓰기

텍스트·장식·효과·모션을 한 컴포지션에 담아 저장하세요. 저장 후 카드에서 썸네일 PNG를 등록할 수 있습니다.

열려 있는 컴프 전체가 대상입니다. 먼저 Ctrl+S로 .aep 저장을 완료하세요. 저장되지 않은 변경 사항이 있으면 보관을 중단합니다. 자동 썸네일 렌더링은 실행하지 않습니다.

저장 범위와 불러오는 방법

① 타이포만 담은 컴프를 열고 Ctrl+S → 이름·분류 입력 → 보관
② 넣을 작업 컴프를 열고 재생 헤드를 이동 → 카드의 현재 컴프에 추가
③ 추가된 프리컴프를 더블클릭해 문구·장식·모션을 편집하세요.

컴프 불러와 열기는 새 사본을 프로젝트에 가져와 열어줍니다. 여기서 에펙 재생으로 모션을 확인할 수 있습니다. 두 불러오기 버튼 모두 매번 별도 사본을 만듭니다.

첫 버전은 프로젝트 전체 AEP 사본을 보관합니다. 불러올 때 다른 컴프도 프로젝트 패널의 폴더에 함께 들어오며, 타임라인에는 선택한 타이포 컴프만 추가됩니다. 작은 전용 타이포 프로젝트에서 저장하면 관리하기 쉽습니다.

폰트·외부 플러그인·이미지·영상 원본은 자동으로 복사되지 않습니다. 원본을 유지하고 다른 PC로 옮길 때는 에펙의 파일 수집(Collect Files)을 이용하세요. 프로젝트 색상 설정이나 같은 이름의 컴프를 참조하는 표현식에 따라 결과가 달라질 수 있습니다.

컴프에 레터박스 만들기

화면비와 색상을 골라 위·아래 막대를 생성합니다. 막대는 별도 도형 레이어여서 영상·텍스트 위에 얹을 수 있고, 생성 후 수치도 수정할 수 있습니다.

현재 활성 컴프에 별도 도형 레이어로 추가합니다. 적용 대상 지정은 필요 없습니다. 실행 취소는 Ctrl+Z입니다.

만들어진 레이어 편집
타임라인에서 ES Letterbox를 선택하세요. 효과 컨트롤의 막대 높이 (%)로 여백을, 색상으로 막대색을, 페이드 (초)로 시작·끝 페이드를 바꿀 수 있습니다. 페이드를 0으로 두면 항상 표시됩니다.

A → B 장면 전환
다음 장면 B를 A보다 위에 놓고, 전환 시간만큼 겹치세요. B 레이어만 지정하여 적용합니다. 시작 지연은 B의 시작점 기준입니다. 여러 요소로 된 장면은 먼저 프리컴프하세요. 레이어 길이와 순서는 자동으로 바꾸지 않습니다. 다른 전환으로 바꿀 때는 기존 전환을 실행 취소한 뒤 적용하세요.
